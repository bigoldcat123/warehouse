# 湿度 / 气体浓度 折线（记录）接口文档

## 1. 基本信息

本文件包含 6 个接口，结构与温度折线接口（`/data/tempRecords`、`/data/layerAvgTemp`、`/data/allAvgTemp`）完全一致，参数、返回结构相同，区别在于：

- **当前湿度和气体浓度没有真实数据**，因此接口根据仓房 `xyz` 维度**生成随机模拟数据**返回（当有真实数据后可替换为真实实现）。

| 指标 | 按点 | 按层平均 | 全仓平均 |
| --- | --- | --- | --- |
| 湿度 | `GET /data/humidityRecords` | `GET /data/layerAvgHumidity` | `GET /data/allAvgHumidity` |
| 气体浓度 | `GET /data/gasRecords` | `GET /data/layerAvgGas` | `GET /data/allAvgGas` |

| 项目 | 说明 |
| --- | --- |
| 请求方式 | 全部 `GET` |
| 鉴权要求 | jwt（与 `/data/tempRecords` 等温度记录接口一致，需携带 `Authorization: Bearer <token>`） |
| 返回格式 | `application/json; charset=utf-8` |
| 返回结构 | 统一使用 `R` 包装，`value` 为 `type_TempRecord[]` 数组 |

## 2. 请求参数

### 2.1 按点（湿度和气体浓度各一个）

| 接口 | 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `/data/humidityRecords` | `houseNo` | String | 是 | 粮房编号（`house` 表的 `HouseNo` 字段） |
| | `ceng` | int | 是 | 层坐标（从 1 开始） |
| | `hang` | int | 是 | 行坐标（从 1 开始） |
| | `lie` | int | 是 | 列坐标（从 1 开始） |
| `/data/gasRecords` | 同上 | | | 参数与湿度按点接口一致 |

### 2.2 按层平均（湿度和气体浓度各一个）

| 接口 | 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `/data/layerAvgHumidity` | `houseNo` | String | 是 | 粮房编号 |
| | `ceng` | int | 是 | 层坐标（从 1 开始） |
| `/data/layerAvgGas` | 同上 | | | 参数与湿度按层接口一致 |

### 2.3 全仓平均（湿度和气体浓度各一个）

| 接口 | 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `/data/allAvgHumidity` | `houseNo` | String | 是 | 粮房编号 |
| `/data/allAvgGas` | `houseNo` | String | 是 | 粮房编号 |

### 2.4 请求示例

```

GET http://{服务器地址}:8080/data/allAvgHumidity?houseNo=003
GET http://{服务器地址}:8080/data/gasRecords?houseNo=003&ceng=1&hang=2&lie=3
```

## 3. 响应说明

### 3.1 统一响应结构

所有接口统一使用 `R` 包装返回：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | String | 状态码，`200` 表示成功，`500` 表示失败 |
| `message` | String | 提示信息，成功为 `success`，失败为错误信息 |
| `show` | String | 前端是否弹窗提示，`0` 表示不弹窗 |
| `value` | Array | 业务数据（见 3.2） |

### 3.2 value 结构（type_TempRecord[]）

`value` 是**数组**，每个元素是一个时间点记录，供折线图按时间序列渲染：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `testDate` | String | 检测时间，格式 `yyyy-MM-dd HH:mm:ss` |
| `temp` | Number | 检测值（湿度为 %，气体浓度为 ppm），统一保留 1 位小数 |

### 3.3 模拟数据说明

| 接口 | 数值含义 | 随机范围 |
| --- | --- | --- |
| `/data/humidityRecords`、`/data/layerAvgHumidity`、`/data/allAvgHumidity` | 湿度（%） | 20.0 ~ 90.0 |
| `/data/gasRecords`、`/data/layerAvgGas`、`/data/allAvgGas` | 气体浓度（ppm） | 300.0 ~ 3000.0 |

- 每个时间点会按仓房配置（`z_num` 层数、`x_num` 行数、`y_num` 列数）生成一张随机三维数组，再按接口类型取值：
  - **按点**：取该坐标（层/行/列）的值；
  - **按层平均**：取该层所有点的平均值；
  - **全仓平均**：取全部点的平均值。
- 模拟序列：**每 4 小时一个点，共 24 个点**（覆盖最近约 4 天），终点为服务器当前整点，按时间升序返回。
- 随机数以「仓房编号 + 指标」为种子生成，**同一仓房、同一指标多次请求数值保持一致**（时间点随当前时间滑动）。
- 模拟数据仅用于前端展示，无真实业务意义，待有真实数据后应替换为真实实现。

### 3.4 响应示例

按点湿度（仓房配置 `z=2`、`x=2`、`y=3`，请求 `ceng=1&hang=2&lie=3`）：

```json
{
  "code": "200",
  "message": "success",
  "show": "0",
  "value": [
    { "testDate": "2026-09-01 10:00:00", "temp": 65.1 },
    { "testDate": "2026-09-01 14:00:00", "temp": 71.5 },
    { "testDate": "2026-09-01 18:00:00", "temp": 55.2 },
    { "testDate": "2026-09-01 22:00:00", "temp": 60.8 }
  ]
}
```

按层平均湿度响应结构完全相同，`temp` 为该层平均值；全仓平均为全部点平均值。气体浓度接口响应结构完全相同，仅数值范围不同。

### 3.5 边界情况

| 场景 | 返回值 |
| --- | --- |
| 粮房编号不存在（`house` 表中查不到） | `value` 为空数组 `[]` |
| 坐标超出仓房维度（层/行/列越界） | `value` 为空数组 `[]` |
| 缺少 `houseNo` / `ceng` / `hang` / `lie` 参数 | 统一异常处理返回 `code=500`、`show=2`、`message` 为服务端错误提示 |

## 4. 错误码

| code | 含义 | 说明 |
| --- | --- | --- |
| `200` | 成功 | 正常返回 |
| `500` | 服务端错误 | 参数缺失或处理异常时返回 |
| `401` / `403` | 未认证 / 无权限 | 未携带或携带无效的 jwt token 时返回（与温度记录接口一致） |

## 5. 前端调用

前端在 `src/api/data/index.ts` 的 `dataApi` 中已封装对应方法，返回类型为 `ResponseData<type_TempRecord[]>`：

```ts
import dataApi from '@/api/data'

// 按点湿度 / 气体浓度
const res = await dataApi.humidityRecords(houseNo, ceng, hang, lie)
const records = res.data?.value ?? []   // type_TempRecord[]

// 按层平均
const res = await dataApi.layerAvgHumidity(houseNo, ceng)

// 全仓平均
const res = await dataApi.allAvgHumidity(houseNo)
const res = await dataApi.allAvgGas(houseNo)
```

页面取 `res.data?.value` 渲染 ECharts 折线，日期范围过滤在本地前端完成（`filterData`），不传接口。
