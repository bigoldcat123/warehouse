# 仓房基础信息设置（warehouse_settings）增删改查接口文档

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 基础路径 | `/warehouseSettings` |
| 数据表 | `warehouse_settings`（仓房基础信息设置表，`house_no` 唯一） |
| 返回格式 | `application/json; charset=utf-8` |

所有接口返回统一使用 `R` 包装：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | String | `200` 成功 / `403` 无权限 / `500` 失败 |
| `message` | String | 提示信息 |
| `show` | String | `0` 不弹窗 / `2` 错误弹窗 / `3` 警告弹窗 |
| `value` | Object | 业务数据（查询类接口返回） |

## 2. 鉴权说明

| 场景 | 结果 |
| --- | --- |
| 请求头带有效登录 token | 允许 |
| dev 环境使用开发 token（`Authorization: Bearer 123456789`） | 全部允许 |
| 使用 guest token（`Authorization: Bearer 1aff8945c9a85255900cbb22f3`） | **只读**：仅 GET 允许，POST/PUT/DELETE 拒绝 |
| 无 token | `{"code":"403","show":"3","message":"无权限访问"}` |

> 请求头格式：`Authorization: Bearer {token}`

## 3. 字段说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Integer | 主键 ID（新增时可不传） |
| `houseNo` | String | 仓房编号（唯一，必填） |
| `temperatureMax` | Number | 温度报警上限值（℃），DECIMAL(5,2) |
| `temperatureCollectTime` | String(HH:mm:ss) | 温度采集时间（几点采集） |
| `temperatureIntervalHours` | Integer | 温度采集间隔时间（小时） |
| `humidityMax` | Number | 湿度报警上限值（%），DECIMAL(5,2) |
| `humidityCollectTime` | String(HH:mm:ss) | 湿度采集时间（几点采集） |
| `humidityIntervalHours` | Integer | 湿度采集间隔时间（小时） |
| `gasMax` | Integer | 气体浓度报警上限值（ppm） |
| `gasCollectTime` | String(HH:mm:ss) | 气体浓度采集时间（几点采集） |
| `gasIntervalHours` | Integer | 气体浓度采集间隔时间（小时） |
| `createTime` | String(yyyy-MM-dd HH:mm:ss) | 创建时间（入库时自动生成，无需传） |
| `updateTime` | String(yyyy-MM-dd HH:mm:ss) | 更新时间（更新时自动刷新，无需传） |

未传的报警上限/采集时间/间隔字段将使用数据库默认值（温度 40.00 / 湿度 85.00 / 气体 100 ppm，采集时间 08:00:00，间隔 2 小时）。

## 4. 接口列表

### 4.1 分页查询设置列表

```
GET /warehouseSettings?current={页}&size={每页条数}&houseNo={仓房编号，可选}&warehouseID={仓库ID，必须}
```

Query 参数均为可选：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `current` | Integer | 否 | 当前页（从 1 开始） |
| `size` | Integer | 否 | 每页条数 |
| `houseNo` | String | 否 | 仓房编号（精确匹配过滤） |
| `warehouseID` | Integer | 否 | 仓库 ID（过滤该仓库下的仓房设置，通过 house 表关联；该仓库无仓房时返回空分页） |

响应示例：

```json
{
  "code": "200",
  "show": "0",
  "message": "success",
  "value": {
    "records": [
      {
        "id": 1,
        "houseNo": "003",
        "temperatureMax": 38.50,
        "temperatureCollectTime": "06:00:00",
        "temperatureIntervalHours": 3,
        "humidityMax": 80.00,
        "humidityCollectTime": "06:00:00",
        "humidityIntervalHours": 3,
        "gasMax": 80,
        "gasCollectTime": "06:00:00",
        "gasIntervalHours": 3,
        "createTime": "2026-09-02 07:03:57",
        "updateTime": "2026-09-02 07:03:57"
      }
    ],
    "total": 1,
    "size": 10,
    "current": 1,
    "pages": 1
  }
}
```

### 4.2 根据 ID 查询

```
GET /warehouseSettings/{id}
```

| 场景 | 响应 |
| --- | --- |
| 存在 | `code:200`，`value` 为设置对象 |
| 不存在 | `code:500`，`message:"没有此条记录"` |

### 4.3 根据仓房编号查询（唯一）

```
GET /warehouseSettings/houseNo/{houseNo}
```

| 场景 | 响应 |
| --- | --- |
| 存在 | `code:200`，`value` 为设置对象 |
| 不存在 | `code:500`，`message:"没有此仓房的设置"` |

### 4.4 新增设置

```
POST /warehouseSettings
Content-Type: application/json

{
  "houseNo": "005",
  "temperatureMax": 42.00,
  "temperatureCollectTime": "07:30:00",
  "temperatureIntervalHours": 4,
  "humidityMax": 88.50,
  "humidityCollectTime": "07:30:00",
  "humidityIntervalHours": 4,
  "gasMax": 120,
  "gasCollectTime": "07:30:00",
  "gasIntervalHours": 4
}
```

成功：`{"code":"200","show":"0","message":"success"}`

| 场景 | 响应 |
| --- | --- |
| 成功 | `code:200` |
| `houseNo` 为空 | `code:500`，`message:"仓房编号不能为空"` |
| 仓房不存在（`house` 表中无此编号） | `code:500`，`message:"没有该仓房"` |
| 该仓房已存在设置（`house_no` 唯一） | `code:500`，`message:"该仓房设置已存在"` |

### 4.5 修改设置（按 id 更新）

```
PUT /warehouseSettings
Content-Type: application/json

{
  "id": 2,
  "temperatureMax": 45.00,
  "humidityMax": 90.00,
  "gasMax": 150
}
```

只传需要修改的字段即可（`id` 必填），未传字段保持原值。

| 场景 | 响应 |
| --- | --- |
| 成功 | `code:200` |
| `id` 不存在 | `code:500`，`message:"没有此条记录"` |

### 4.6 删除设置

```
DELETE /warehouseSettings/{id}
```

| 场景 | 响应 |
| --- | --- |
| 成功 | `code:200` |
| `id` 不存在 | `code:500`，`message:"error"` |

### 4.7 查询指定仓库下未设置的仓房列表

```
GET /warehouseSettings/unset/{warehouseId}
```

查询指定仓库（warehouse）下**尚未设置基础信息**的仓房列表。`house` 与 `warehouse_settings` 为一对一关系（按 `house_no` 关联），已设置有记录的仓房会被过滤。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `warehouseId` | Integer | 是 | 仓库 ID（路径参数） |

响应示例：

```json
{
  "code": "200",
  "show": "0",
  "message": "success",
  "value": [
    {
      "id": 12,
      "houseNo": "004",
      "houseName": "P4",
      "warehouseID": 8
    }
  ]
}
```

> `value` 为未设置的仓房数组，元素是完整的仓房对象（含 `id`、`houseNo`、`houseName`、`warehouseID` 等字段）。前端可用 `houseNo` 直接作为新增设置请求体的 `houseNo`。

| 场景 | 响应 |
| --- | --- |
| 存在未设置的仓房 | `code:200`，`value` 为仓房数组 |
| 该仓库下所有仓房均已设置 | `code:200`，`value` 为空数组 `[]` |
| 仓库不存在或仓库下无仓房 | `code:200`，`value` 为空数组 `[]` |

示例：

```bash
curl "http://localhost:8080/warehouseSettings/unset/8" -H "Authorization: Bearer {token}"
```

## 5. 错误码汇总

| code | 含义 | 触发场景 |
| --- | --- | --- |
| `200` | 成功 | 正常返回 |
| `403` | 无权限 | 未携带 token 或 guest token 执行写操作，`message:"无权限访问"` |
| `500` | 业务失败 | 参数校验不通过、记录不存在、仓房不存在等，`message` 为具体原因 |
