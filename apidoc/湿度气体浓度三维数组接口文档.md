# 湿度 / 气体浓度 三维数组接口文档

## 1. 基本信息

本文件包含两个接口，结构逻辑与温度三维数组接口（`/data/temperatureCube`）一致，区别在于数据来源：

- **当前湿度和气体浓度没有真实数据**，因此接口根据仓房 `xyz` 维度**生成随机模拟数据**返回。

| 项目 | 湿度接口 | 气体浓度接口 |
| --- | --- | --- |
| 接口名称 | 根据粮房编号获取每个采集时间点的湿度三维数组 | 根据粮房编号获取每个采集时间点的气体浓度三维数组 |
| 请求方式 | `GET` | `GET` |
| 接口路径 | `/data/humidityCube` | `/data/gasCube` |
| 鉴权要求 | jwt | jwt |
| 返回格式 | `application/json; charset=utf-8` | `application/json; charset=utf-8` |


## 2. 请求参数

### 2.1 Query 参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `houseNo` | String | 是 | 粮房编号（`house` 表的 `HouseNo` 字段） |

### 2.2 请求示例

```
GET http://{服务器地址}:8080/data/humidityCube?houseNo=003
GET http://{服务器地址}:8080/data/gasCube?houseNo=003
```

使用 curl：

```bash
curl "http://localhost:8080/data/humidityCube?houseNo=003"
curl "http://localhost:8080/data/gasCube?houseNo=003"
```

## 3. 响应说明

### 3.1 统一响应结构

所有接口统一使用 `R` 包装返回：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | String | 状态码，`200` 表示成功，`500` 表示失败 |
| `message` | String | 提示信息，成功为 `success`，失败为错误信息 |
| `show` | String | 前端是否弹窗提示，`0` 表示不弹窗 |
| `value` | Object | 业务数据（见下方说明） |

### 3.2 value 结构

`value` 是一个对象（Map），只有一个键值对：

- **key**：采集时间，取服务器当前时间（精确到秒），格式为 ISO-8601 字符串，如 `2026-09-02T11:33:06`；
- **value**：三维数组 `[层][行][列]`，即 `[z][x][y]`，每层是一个「行 × 列」的二维数组。

其中维度取值来自 `house` 表的仓房配置：

| house 字段 | 含义 | 维度 |
| --- | --- | --- |
| `z_num`（`z`） | 层数 | 第一维（层） |
| `x_num`（`x`） | 行数 | 第二维（行） |
| `y_num`（`y`） | 列数 | 第三维（列） |

数组元素为**字符串**类型的模拟数值，统一保留 1 位小数（如 `"65.1"`）。

### 3.3 模拟数据范围

| 接口 | 数值含义 | 随机范围 |
| --- | --- | --- |
| `/data/humidityCube` | 湿度（%） | 20.0 ~ 90.0 |
| `/data/gasCube` | 气体浓度（ppm） | 300.0 ~ 3000.0 |

> 模拟数据每次调用都会重新随机生成，仅用于前端展示，无真实业务意义。

### 3.4 响应示例

湿度接口（仓房配置 `z=2`、`x=2`、`y=3`，即 2 层 × 2 行 × 3 列）：

```json
{
  "code": "200",
  "message": "success",
  "show": "0",
  "value": {
    "2026-09-02T11:33:06": [
      [
        ["65.1", "71.5", "22.0"],
        ["35.1", "61.2", "84.0"]
      ],
      [
        ["82.7", "22.7", "35.7"],
        ["65.0", "55.1", "46.8"]
      ]
    ]
  }
}
```

气体浓度接口响应结构完全相同，仅数值范围不同。

### 3.5 边界情况

| 场景 | 返回值 |
| --- | --- |
| 粮房编号不存在（`house` 表中查不到） | `value` 为空对象 `{}` |
| 缺少 `houseNo` 参数 | 统一异常处理返回 `code=500`、`show=2`、`message` 为服务端错误提示 |

## 4. 错误码

| code | 含义 | 说明 |
| --- | --- | --- |
| `200` | 成功 | 正常返回 |
| `500` | 服务端错误 | 参数缺失或处理异常时返回 |

> 由于这两个接口为公开接口（无需鉴权），正常不会返回 `401` / `403`。
